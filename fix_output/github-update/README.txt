Архив для GitHub Release (автообновление в программе)
=====================================================

Скрипт: pack_github_update.ps1 (или pack_github_update.bat из корня проекта).

Порядок:
  1. Соберите проект: build.bat  →  появится dist\WboBAMP\
  2. Запустите: pack_github_update.ps1
  3. В fix_output\github-update\ будет файл вида:
         update_WboBAMP_v0.1.2.2.3.zip

Его загружайте в релиз на GitHub как asset.

Почему не архив только с main.py / ui_common.py:
  В собранной версии (.exe) код лежит внутри PyInstaller (папка _internal и др.).
  Автообновление копирует файлы из ZIP в каталог программы; для .exe нужна
  полная папка dist\WboBAMP, иначе патч не обновит приложение.

Имя файла:
  В коде updater ищет в релизе ZIP с подстрокой "update" в имени — имя
  update_WboBAMP_v...zip этому соответствует.

Структура ZIP:
  Один корневой каталог WboBAMP\ (как после сборки) — так ожидает распаковка в приложении.

Примечание:
  Запущенный .exe при обновлении не перезаписывается; обновляются остальные файлы,
  затем программа перезапускается. Для смены самого загрузчика .exe может понадобиться
  полная установка из установщика.
